# RayoPDF 0.4.0 on the harness, 2026-11-15

0.4.0 adds two output options for conventions (`--tables=pipe`, `--quotes=ascii`), the first small
model in the core (M9: the edge-row furniture model), table and formula rules, to the converter of
[0.3.0](v0.3.0-2026-11-14.md). Every quality step landed only through the strict gate (no gated
metric of any development or validation suite more than 0.0001 below its best). Quality and speed
were measured on the release's code (`a1db445`); the holdouts (`readoc` and the weasyprint
producer) once, on this code. Same machine and harness as [the baselines](baselines-2026-11-05.md);
the release check is [release-check-2026-11-15](release-check-2026-11-15.md).

## New since 0.3.0

- **Output options:** `--tables=pipe` writes every table as a GitHub pipe table, a spanning cell's
  text in its first row and column and the cells it covers empty, header rows after the first as
  body rows; `--quotes=ascii` writes typographic quotation marks as `'` and `"`; `--tables=html`
  sets a space between a row's tags and around each cell's text, as HTML pretty-printers do.
- **Declared profiles:** READoc's suites add `--tables=pipe` (its evaluator reads pipe tables
  only), opendataloader-bench adds `--quotes=ascii`, OmniParseBench adds `--math=latex` (its math
  tests compare LaTeX).
- **Small model (M9):** the edge-row furniture model ships: LightGBM trees trained on DocLayNet's
  train selection and compiled into the binary take running heads and footers the rules keep at a
  page's edge; the rows they take still count in every page statistic, and only the paragraphs
  and headings they alone make are left out
  ([decision](../development/ocr_ml_decision.md#small-models-in-the-core-m9)).
- **Tables:** rules drawn cell by cell (ConTeXt) part columns set a word space apart; cells set
  to the middle of their row (HTML's default) stay one row; a row label centred between two rows
  splits no row; a table continued right under itself with the same columns joins it; a lone rule
  with text beside it at its height is a fraction bar, not a table; emphasis over a lone body cell
  is kept.
- **`--furniture=keep`:** kept page furniture at a page's foot follows the notes printed above it.
- **LaTeX mode:** a formula whose accents the rebuild cannot attach is read again as the cheapest
  tree joining its glyphs (unless it is a paragraph's whole text); Greek prose with accented or
  polytonic letters stays text.
- **Speed:** two of the new rules rewritten before landing to cost a fraction of their first form,
  and `src/hot.ld` regenerated ([performance.md](../development/performance.md#040-2026-11-15)).

## Tried and not landed

Every quality step went through the strict gate (no gated metric more than 0.0001 below its best
on any development or validation suite); a step that failed it took one fallback.

- **Edge-row model with a heading guard** (the first retry of 0.3.0's model): it left out the rows
  the semantics would make headings or captions, and the gate still measured DocLayNet validation
  `heading_f1` 0.695899 → 0.695616 (−0.00028), the drop of 0.3.0. The fallback, removals that
  change nothing but the rows taken, passed and ships.
- **A lower threshold for the edge-row model:** with removals local, τ 0.90, 0.85, 0.80 and 0.75
  would raise doclaynet-dev `furniture_f1` from 0.5966 to 0.5979, 0.5986, 0.5994 and 0.6003 and
  olmOCR `headers_footers` from 0.8499 to 0.8526 (0.8552 at 0.75), but every τ below 0.930 takes
  the first line of eight `rayomd-tech` fixtures ("Sentinel start …", scored 0.9195 to 0.9300):
  synthetic untagged MHS 0.9373 → 0.9277. Only τ 0.9305 passed (eleven page numbers more on
  doclaynet-dev, `furniture_f1` +0.0001), 0.0005 above that line and set by hand in a file only
  the training writes: not taken.
- **More opendataloader-bench conventions,** measured and left out: footnote numbers kept from
  the source under `--plain` (+0.0002), line-break hyphens kept (+0.0000), small capitals in upper
  case (+0.0003, but READoc `head_teds` lower), header cells as `<td>` (+0.0005, header semantics
  lost), dashes and ellipses in ASCII (+0.0002 and +0.0001; a dash written `-` at a line's end
  would be dehyphenated).
- **READoc arXiv tables:** of the 66 development documents whose `table_teds` trails docling's
  by 0.1 or more or is below 0.5, 26 hold a pipe table READoc's evaluator cannot read (a `%` or
  `&` in a cell); false tables (10), missing tables (7) and merged columns (3) have a different
  cause in nearly every document, so no rule was written for them.
- **Speed:** a profile-guided build was not tried again (the profile must first come out the same
  on any machine; [tenth round](../development/performance.md#tenth-round-2026-11-13)); the image
  round overlapped with the layout and `--serve` with `--batch`'s allocator settings stay open
  candidates.
