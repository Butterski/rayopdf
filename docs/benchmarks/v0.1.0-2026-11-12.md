# RayoPDF 0.1.0 on the harness, 2026-11-12

0.1.0 is the first release. It ships with every item of the release bar met except one key,
READoc arXiv `table_teds`, which is named as open ([release check](release-check-2026-11-12.md));
the user decided on 2026-11-11 to release with it open. Measured on code `c1116f0` (core alone
unless the bundle is named); the holdouts (`readoc`, the weasyprint producer) were measured once,
on this code. Same machine and harness as [the baselines](baselines-2026-11-05.md).

Since [0.0.15](v0.0.15-2026-11-11.md) (round 8):

- **Tables (D6):** a header label spanning rows and a cell without text that spans rows or columns
  are written in pipe tables; HTML is kept for a body cell with text spanning rows, and for a body
  cell spanning columns under a header of several rows. A body line holding one label across the
  other lines' column gaps is a label row. Measured on the READoc validation split before landing
  (+0.015 and +0.0025; odl TEDS 0.896 → 0.889 for the first, waived: docling 0.879).
- **Formula scripts** in the default mode are written in Unicode superscript and subscript forms
  where every character has one (mc², x₀); text scripts (H<sub>2</sub>O, 1<sup>st</sup>) and
  scripts without forms stay `<sup>`/`<sub>` (synthetic sup/sub construct F1 0.07-0.09 →
  0.40-0.44).
- `src/hot.ld` regenerated (byte-identical output).
