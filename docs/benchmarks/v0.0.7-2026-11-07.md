# RayoPDF 0.0.7 on the harness, 2026-11-07

What changed since [0.0.6](v0.0.6-2026-11-06.md):

- **Tagged PDF (M6):** the structure tree (RoleMap, ParentTree, marked-content ids in pages and
  Form XObjects, OBJR, `/Alt`, `/ActualText`, artifacts) is read, checked with the four criteria of
  [algorithms §6.10](../research/algorithms.md#610-tagged-pdf-as-the-primary-signal) and, when it
  passes, decides blocks, tables (with spans, across pages), lists, figures with alt text and the
  reading order. Untagged files and rejected trees take the geometry path unchanged.
  `--no-structure` turns it off; `--report` gives the outcome.
- **Product (M7 without the performance campaign):** `--batch`, `--serve --json` (RayoMD's
  protocol 1), `--workers=N` with output independent of N (clean under ThreadSanitizer), one
  record shape for every mode, a static Windows build (MinGW-w64, tested under Wine), and
  reproducible release archives (`tools/package.py`). The build image is now `rayopdf-build:2`.
- **Semantics:** inline styles decided per glyph with correct nesting; math italics no longer
  emphasis; strikethrough from rules through the glyphs; GitHub alerts; adjacent listings kept
  apart; title blocks, running heads and display math no longer headings; heading levels from
  section numbers; link text without trailing punctuation; URLs broken over two lines rejoined;
  right-to-left run boundaries without stray spaces.
- **Reading order:** header and footer blocks of up to four rows with publication metadata (DOI,
  URL, copyright, licence, ISSN) as furniture evidence; columns of short lines beside a text
  column.
- **Tables:** charts no longer read as tables (evenly stepped axis numbers); form grids; rows
  below a ruled grid that keep its columns; body re-tried without a misleading header; header
  labels attached to narrow numeric columns.
- **Text:** untrustworthy ToUnicode maps are detected and repaired (tab-mapped spaces, Adobe
  Symbol and Wingdings private-use characters, Thai private-use marks, numeric glyph names,
  Macintosh glyph order for bare TrueType subsets).
- **Images:** an own baseline and progressive JPEG decoder (forked from RayoMD GUI); CMYK/YCCK
  JPEGs written in the colours viewers show; DCT images with soft masks written as PNG with
  alpha; masks that cannot be applied counted as `images_mask_dropped`.
- **OCR/ML gate (M8):** measured; see [ocr_ml_decision.md](../development/ocr_ml_decision.md).

Same machine and harness as [the baselines](baselines-2026-11-05.md). RayoPDF ran as the harness's
`cli` tool: `build/static/rayopdf` (GCC 13.3, `-O2`, fully static, 2,669,136 bytes; +395,680 for
the structure tree, the JPEG decoder, ToUnicode repair and the batch/serve front ends),
`rayopdf --convert {in} {out}` with its default image output. All numbers are reproduced here.

## Robustness

- Full conversions with ASan + UBSan, images written (2,802 PDFs: synthetic, odl, olmOCR
  born-digital, SafeDocs): 0 crashes, 0 hangs, 0 sanitizer reports — after a fix: the first
  sweep found a heap-buffer-overflow in the tagged path on 3 SafeDocs files (an inline image
  glyph added after the structure tables were sized); the fix has a test and a fuzz regression,
  and `fuzz_layout_structure` now draws inline images.
- Core tests pass under ASan + UBSan, ThreadSanitizer and Wine (Windows build); CLI verifier
  60/60.
- Five-minute fuzz runs on each owner's final code, all clean: `fuzz_layout_content` (132,048
  runs), `fuzz_layout_document` (1.98 M), `fuzz_layout_tables` (30,879), `fuzz_layout_structure`
  (182,865), `fuzz_text_cmap` (5,392), `fuzz_text_program` (12,844), `fuzz_text_repair`
  (1,507,996), `fuzz_image_decode` (79,030), `fuzz_image_jpeg` (90,049), `fuzz_common_serve`
  (2.1 M). Four new targets: structure, text repair, JPEG, serve requests.

## Known gaps

- Construct F1 0.930 (gate 0.95): `<sup>`/`<sub>` math (D6), LaTeX quote environments, code in a
  proportional font, display formulas split into one-line paragraphs.
- READoc arxiv: `head_teds` 0.469 and `table_teds` 0.481 below the best tool; flowcharts drawn
  as boxes still read as tables.
- olmOCR `headers_footers` 0.707 against docling's 0.898 (running titles odl keeps).
- `xelatex-2col` NID 0.929 (gate 0.95): Unicode display math against TeX ground truth.
- JPX images and masks in JBIG2/CCITT/JPX keep no alpha (`images_mask_dropped`).
- Images are decoded whole (188 MiB peak on a 4653×2334 RGB image with a soft mask).
- Speed: 0.94 ms/page in process against the release bar's 0.5 ms (≥ 2,000 pages/s).
- OCR (M8 branch c) is decided, not built.
