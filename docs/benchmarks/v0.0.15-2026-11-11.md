# RayoPDF 0.0.15 on the harness, 2026-11-11

0.0.15 is round 7: tables on scientific papers, page furniture on single pages, Markdown escaping,
and the instruction cost of the round won back (method and steps:
[performance.md](../development/performance.md#seventh-round-furniture-and-table-landings-won-back-2026-11-11)).
Same machine and harness as [the baselines](baselines-2026-11-05.md); measured on code `a285266`
(core alone unless the bundle is named). The holdouts (`readoc`, the weasyprint producer) were
measured once, on this code. New in the harness: the READoc validation split `readoc-val` (300
arXiv and 300 GitHub papers after the development split in the same order, aggregate only, in the
quality gate since this round; [evaluation.md](../development/evaluation.md)).

On 2026-11-11 the user decided that READoc arXiv `table_teds` is held to docling's number under
bar item (b), not to the best text-layer tool's (roadmap, Goal and release bar).

What changed in the output, each rule general and tested, each step landed through the quality
gate:

- **Tables:** header levels from centred labels and partial rules (`\cmidrule`); touching shaded
  stripes one table; labels at column starts and title bands as rows; plot dots are no rulings;
  figure text by word reach and grids inside figure regions are drawing; justified prose under
  rules is no table; header lines set at the body's row pitch stay rows; rows from a word of the
  band's size; header lines above a run without a top rule; close columns of numbers; a body cell
  spanning columns is repeated in each column of a pipe table under a one-row header (D6).
- **Page furniture** on single pages: blocks of up to six rows that end in a strong row; deeper
  running heads; page numbers in other languages; folio rows close to the text; rows of a few
  words that the producer marked as artifacts at a page's edge.
- **Escaping:** `*` and `_` are escaped only where CommonMark could read them as emphasis
  delimiters, so significance marks (`0.05**`) are written as they are.
