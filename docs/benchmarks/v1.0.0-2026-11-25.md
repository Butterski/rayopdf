# RayoPDF 1.0.0, 2026-11-25

1.0.0 is the converter of [0.5.0](v0.5.0-2026-11-24.md), released as the first stable version
with the repository public. The converter's code is unchanged: a static build of 1.0.0 and one
of 0.5.0 have the same size (3,992,024 B) and differ in 30 bytes, the version string `0.5.0` →
`1.0.0` in its five places and the build ID that hashes the file. Every document converts to the
same output, so every quality and speed number of [0.5.0's record](v0.5.0-2026-11-24.md) is
1.0.0's, and the [benchmark summary](../benchmarks.md) gives them for 1.0.0; the JSON output's
`rayopdf` field carries the new version.

## New since 0.5.0

- **Documentation:** a user-first README, guides for the command line, the output formats, the
  OCR add-on, Python, JavaScript, C and C++, the container image and AI agents
  ([docs/guide](../guide/)), an [index](../README.md), and a public
  [benchmark summary](../benchmarks.md) with what each benchmark measures, the tools and
  versions compared, where other tools lead and how to reproduce every number.
- **Branding:** the RayoMD mascot in RayoPDF's colours, its document in PDF red
  (`docs/assets/branding/rayopdf.svg`, vector, traced from RayoMD's mascot).
- **Python on PyPI:** `pip install rayopdf` (Linux x64 with glibc 2.28 or newer, Windows x64).
- **Benchmarks published:** RayoPDF's opendataloader-bench results submitted to the
  benchmark's repository in its own format
  ([opendataloader-bench#40](https://github.com/opendataloader-project/opendataloader-bench/pull/40)).

## Quality and speed

As 0.5.0 (measured 2026-11-24 on an AMD Ryzen 5 PRO 4650GE): opendataloader-bench 0.944 in its
conventions (0.917 default), READoc arXiv on the test set 0.893 text, 0.719 headings, 0.730
tables in READoc's conventions, olmOCR-bench arXiv math 0.860 with `--math=latex`, headers and
footers 0.891, multi-column 0.762 in olmOCR's conventions; a one-page PDF in 0.91 ms as a fresh
process (median of opendataloader-bench's 200 pages), 2,207 pages a second warm on one core.
The release check is [release-check-2026-11-25](release-check-2026-11-25.md).
