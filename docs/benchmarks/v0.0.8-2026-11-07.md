# RayoPDF 0.0.8 on the harness, 2026-11-07

0.0.8 is the first performance campaign (method, steps and rejected attempts:
[performance.md](../development/performance.md)). Output is byte-identical to
[0.0.7](v0.0.7-2026-11-07.md): 5,535 comparisons over the synthetic corpus, odl, olmOCR
born-digital and SafeDocs with and without images, `--batch --workers=1` against `--workers=4`,
and the harness's own runs of all four suites (Markdown and image files) — so every quality number
of 0.0.7 stands.

Kept steps: a `--bench` loop mode and a perf image for measuring; `fmin`/`fmax` inlined with
glibc's results; content-stream numbers read in one pass, integer and fraction digits in separate
loops; glyph names found by table offset; one ToUnicode check counted in a hash table; font
metrics read once per string and a fast path for ASCII text; an exact "no duplicate" filter
before the duplicate-glyph probe; base-encoding glyph texts built once per process; image alpha
composed a row at a time and PNG files built without zero-fill.

`build/static/rayopdf`: GCC 13.3, `-O2`, fully static, 2,690,032 bytes.

## Speed and memory

Harness, fresh process started from Python, one pinned core, 200 odl PDFs and 6 multi-page
synthetic PDFs:

| run | pages/s | ms/page median | ms/page p95 | peak RSS MiB |
|---|---|---|---|---|
| 0.0.7, `--images=none` | 330.4 | 3.05 | 4.33 | 13.5 |
| 0.0.8, `--images=none` | 365.3 | 2.90 | 3.94 | 13.4 |
| 0.0.7, images written (default) | 128.3 | 3.50 | 32.30 | 188.6 |
| 0.0.8, images written (default) | 147.7 | 3.15 | 26.83 | 95.7 |

In process (release libraries, CPU 3, the 200 odl PDFs, best of 3 per document, images off,
three alternating rounds; file reading and writing not timed): 0.0.7 0.948–0.954 ms/page median
and 2.03–2.06 p95; 0.0.8 0.666–0.668 median (−30 %, about 1,500 pages/s) and 1.39–1.41 p95.

Native fresh-process timer (posix_spawn, CPU 3, 11 runs per document after 2 untimed, binaries
copied into the container's own file system, odl, `--images=none`): 0.0.7 1.72–1.73 ms per
document median, 0.0.8 1.49–1.51 ms (−13 %). `--inspect` in the same setup: 0.286 ms for both
(empty static program 0.215 ms); from a bind-mounted host directory the same binary takes
0.37 ms, which is what the 0.0.7 record measured.

Release bar: warm ≥ 2,000 pages/s (≤ 0.5 ms/page) and fresh ≤ 1 ms/page are not met; the
remaining cost is spread (no function above 13 % of cycles: inflate, content lexer, glyph
placement, line building, duplicate folding, writer, tables). Peak RSS with images written is
halved but still grows with the largest image.

## Robustness

Core tests pass under ASan + UBSan and ThreadSanitizer, the Windows build under Wine; CLI
verifier 63/63; full conversions with ASan + UBSan over 2,802 PDFs: 0 crashes, 0 hangs, 0
sanitizer reports; 0 warnings on debug, release, static, asan and Windows builds.
